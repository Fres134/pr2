# Ticket Journal

Project for ticket management and processing.

### ISSUE-1: Создание заявки
Функция `add_ticket()` добавляет новую заявку в CSV-файл с автоматической датой создания.

### ISSUE-3: Экспорт открытых заявок
Функция `export_open_tickets()` экспортирует все открытые заявки в отдельный CSV-файл.
